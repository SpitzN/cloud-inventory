# Cloud Inventory

Browse cloud Resources, group a Selection into an Application, and view Applications as a graph. There is no backend; state is held in the client.

## Run it

```
pnpm install && pnpm dev
```

`pnpm check` runs the typecheck, the lint, the format check and the tests, and is what the pre-commit hook runs.

## Where things are

The documents under [docs/](./docs/) describe the product, the screens, the dataset, the architecture and the checks; [GLOSSARY.md](./GLOSSARY.md) defines the terms.
